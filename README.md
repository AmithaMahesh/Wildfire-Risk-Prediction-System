# Wildfire Big Data Project

A Big Data project using Apache Spark, Scala, Hadoop HDFS, and Python
for weather data processing, wildfire risk analysis, and dashboarding.

## Technologies
- Apache Spark
- Scala
- Hadoop HDFS
- Spark MLlib
- Python
- Flask and Leaflet

## Project Structure
- src/main/scala/ - Scala source files
- static/ - Dashboard assets
- build.sbt - Scala build configuration
- dashboard_server.py - Dashboard server
- social_generator.py - Social data generator
- weather_generator.py - Weather data generator

## Build
Run `sbt package` from the project root after installing the required
dependencies.
